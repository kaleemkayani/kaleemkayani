# Kaleem Kayani — GitHub-style Portfolio

A responsive portfolio mockup inspired by the supplied GitHub profile screenshot. Built with HTML and CSS, with a tiny JavaScript snippet to render the decorative contribution grid.

## Run it
1. Download and unzip this folder.
2. Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a repository named `kaleemkayani.github.io` (replace `kaleemkayani` with your actual GitHub username if different).
2. Upload `index.html` to the repository root.
3. In Settings → Pages, enable deployment from the `main` branch and root folder.
4. Replace placeholder email, social links, project links, and demo language percentages with real information.

Note: GitHub's actual profile page cannot be fully restyled with custom CSS. This is a separate portfolio website that recreates the visual style.
