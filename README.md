# Kaleem Kayani — Professional Portfolio

Responsive personal portfolio built with HTML, CSS, and a small amount of JavaScript. No framework or build tools required.

## Publish on GitHub Pages
1. Open the repository `kaleemkayani.github.io`.
2. Upload `index.html` to the repository root (not inside another folder).
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait a few minutes, then visit https://kaleemkayani.github.io.

## Personalize before sharing
- Replace `your-email@example.com` with your public contact email, or remove that button.
- Verify each project exists and update links to its real repository.
- Remove any skills you have not started learning.
- Project cards marked as concepts are examples/placeholders, not claims that the repositories already exist.
